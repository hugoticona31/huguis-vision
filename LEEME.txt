HUGUIS VISION - paquete inicial PWA
1. Sube TODOS los archivos de esta carpeta a la raíz de un sitio web HTTPS.
2. La página principal es index.html.
3. manifest.webmanifest y sw.js habilitan la configuración PWA básica.
4. La instalación requiere publicar primero el sitio en HTTPS.
5. Este paquete es un prototipo visual: aún no contiene videos reales, cuentas, base de datos ni panel administrativo.
